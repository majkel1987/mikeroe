Workflow Guide v1.0

Pencil + Antigravity Freelance Dev Stack Design → Code → Deploy → Zarabiaj

Kompletny workflow do budowania stron internetowych po godzinach — od wizualnego projektu w Pencil, przez generowanie kodu w Antigravity, aż po wdrożenie na produkcję.

Pencil.dev — Visual IDE Canvas
Google Antigravity — Agentic IDE
Claude Code — AI Backend
Vercel — Deploy
01 — Stack Overview

Dlaczego właśnie ten stack?

Pencil i Antigravity uzupełniają się idealnie: Pencil zajmuje się warstwą wizualną, Antigravity warstwą agentową i deploymentem. Razem eliminują oba główne wąskie gardła freelancerskiego workflow — czas na design i czas na kodowanie.

🎨

Pencil.dev

Figma-like canvas wewnątrz IDE. Projekty w formacie .pen żyją w Git. Przez MCP przekazuje dokładne koordynaty wektorowe do AI — nie screenshoty.

🚀

Google Antigravity

Darmowy agentic IDE od Google. Agent autonomicznie planuje, koduje, testuje w przeglądarce i deployuje na Cloud Run. Obsługuje Claude Sonnet 4.5 za darmo.

⚡

Synergia MCP

Pencil eksportuje design przez MCP → Antigravity agent odczytuje i generuje pixel-perfect React/HTML/CSS bez ręcznego kopiowania wartości.

💰

Koszty

Antigravity: darmowy (Gemini 3 Pro) + Claude Sonnet 4.5 gratis. Pencil: darmowy early access. Potrzebujesz tylko Claude Code ($20/mies.) do Pencil.

03 — Workflow

Proces krok po kroku

1
Brief & Struktura Antigravity Agent

Agent generuje plik SPEC.md z architekturą strony na podstawie twojego opisu.

→W Agent Manager wpisz: "Stwórz spec dla landing page fullstack developera z Polski. Sekcje: hero, usługi, portfolio, technologie, kontakt. Stack: Next.js 14 + Tailwind."
→Agent tworzy SPEC.md, folder struktury i package.json
→Review Artifact — zatwierdź lub zostaw komentarz inline jak w Google Docs
2
Visual Design Pencil.dev

Projektujesz każdą sekcję na canvas. Pencil zapamiętuje tokeny designu jako JSON w repo.

→Otwórz nowy plik /design/landing.pen w Pencil
→Zaprojektuj sekcję Hero: prompt w Pencil "Dark tech hero with glassmorphism card, developer avatar left, headline right"
→Iteruj wizualnie — zmieniaj kolory, spacing, typografię bezpośrednio na canvas
→Opcja: skopiuj frame z Figmy → wklej do Pencil (zachowuje layers + auto-layout)
→git add design/landing.pen && git commit -m "design: hero section"
3
Design → Code Pencil MCP + Antigravity

Antigravity agent odczytuje .pen przez MCP i generuje pixel-perfect komponenty React.

→W Agent Manager: "Wygeneruj komponent HeroSection.tsx na podstawie design/landing.pen, sekcja 'hero'. Użyj Tailwind, shadcn/ui, animacje Framer Motion."
→Agent odczytuje JSON z .pen → widzi dokładne px, spacing, kolory → pisze czysty kod
→Agent uruchamia npm run dev i testuje komponent we wbudowanej przeglądarce
→Jeśli są rozbieżności (>4px) — agent wraca do Pencil canvas i koryguje
→Powtórz dla każdej sekcji: ServicesSection, PortfolioGrid, TechStack, ContactForm
4
Polish & Optymalizacja Antigravity Browser

Agent automatycznie testuje responsywność, a11y i performance w wbudowanej przeglądarce Chrome.

→"Sprawdź responsywność na 375px, 768px, 1440px. Zrób screenshoty każdej breakpointy."
→"Uruchom Lighthouse audit i napraw wszystkie błędy performance <90."
→Agent generuje Walkthrough Artifact — dokument z wynikami i poprawkami
→Opcja: SEO meta tags, OpenGraph images, sitemap.xml — wszystko przez agenta
5
Deploy Vercel / Cloud Run

Jedna komenda lub agent deployuje — Vercel dla Next.js (rekomendowane), Cloud Run dla bardziej złożonych projektów.

→Vercel (szybciej): npx vercel --prod lub push do GitHub = auto-deploy
→Cloud Run (Antigravity): "Deploy this app to Cloud Run with service name 'michal-dev'"
→Agent konfiguruje DNS, SSL, environment variables automatycznie
→Wyniki: Walkthrough Artifact z URL produkcyjnym + checklist weryfikacji
⏱ Szacowany czas: Landing page dla klienta (10 sekcji) — 4–6 godzin vs tradycyjne 2–3 dni. Pierwsza strona (twoja wizytówka) może zająć więcej — to inwestycja w opanowanie workflow.
